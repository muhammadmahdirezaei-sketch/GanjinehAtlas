انتشار رایگان با GitHub Pages:
1. وارد https://github.com شوید.
2. یک repository جدید به نام ganjineh-atlas بسازید.
3. index.html را در ریشه repository بارگذاری و commit کنید.
4. Settings > Pages را باز کنید.
5. Deploy from a branch را انتخاب کنید، branch را main و folder را /(root) بگذارید و Save کنید.
6. بعد از انتشار، نشانی معمولاً https://USERNAME.github.io/ganjineh-atlas/ خواهد بود.
